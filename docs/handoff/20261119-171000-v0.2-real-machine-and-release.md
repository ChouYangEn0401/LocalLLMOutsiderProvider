## [安裝流程與環境確認]

```bash
git clone -b dev https://github.com/ChouYangEn0401/LocalLLMOutsiderProvider
cd LocalLLMOutsiderProvider
python -m venv .venv
.venv/bin/pip install -e ".[dev,secure]"      # Windows：.venv\Scripts\pip
.venv/bin/python -m pytest -q                 # 基準：預期 1282 passed，記下實際數字
```

- Python 3.11 以上；Docker 驗證需要有 Docker 的機器；Windows 實測需要 Ollama 或 LM Studio 與一個模型。
- 不需要任何祕密；cloudflared 快速通道不用帳號，具名通道的 `TUNNEL_TOKEN` 從環境的 secret 讀。
